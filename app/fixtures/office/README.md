# Office conversion fixtures

These synthetic fixtures were generated by the former desktop `check-office.py --generate-fixtures` using Python's standard library and LibreOffice. That desktop script has been removed; the committed fixtures remain inputs for the independent service's Office adapter. The image is the existing PractiQ icon. No user documents or model output are included.

- `中文 试卷.docx`: Chinese text, fraction, image, 70-row table spanning pages.
- `中文 表格.xlsx`: visible and hidden sheets, Chinese, string `001`, formula `1+2` with cached value `3`, formatted date, merged cells, and data outside the print area.
- `.doc` / `.xls`: conversions of the corresponding OOXML fixture using LibreOffice's `MS Word 97` / `MS Excel 97` filters.

Regeneration requires Writer, Calc and Chinese fonts. Test runs use these committed inputs; they do not regenerate legacy files. Output fidelity is evaluated separately from AI parsing.


`regressions/table-ending.docx` preserves the original table-ending failure:
it is the committed DOCX fixture with only the final `结束 END` paragraph removed.
The private text-conversion snapshot adds an empty paragraph after a terminal
Word table, leaving the original bytes and all content unchanged. The final
section properties and namespaces remain in place. PDF export is unaffected.

For the deployed engine, inspect fraction numerator/denominator text, image presence
and exactly one final table row in the converted outputs. The private service worker normalizes legacy DOC to a temporary DOCX before
PDF export because direct DOC PDF export can omit the fraction's digits. Both
stages use the same pinned engine and timeout, with separate hardened profiles
and bounded intermediate output. The original DOC and its metadata stay intact;
the DOCX is private and only the final PDF is returned.

`27b8e595c7d8a136dd5d20f19d1236e9a9ca857174318a2421fc143d5f4c09c6`.
Historical source-worker evidence with LibreOffice 26.8.0.3 preserved the

Configure `AI_OFFICE_EXECUTABLE` and its exact `AI_OFFICE_VERSION` as described in
the [service Office guide](../../../server/docs/desktop-office.md). From `server/`,
use an existing Python 3.14+ interpreter to convert these fixtures without starting
a task or calling a model. This writes a fresh temporary output directory and
retains source/output hashes for inspection:

```sh
AI_PYTHON=/absolute/path/to/python3.14
AI_READ_ONLY=1 AI_SERVICE_TOKEN=local-conversion-only PYTHONPATH=src "$AI_PYTHON" - <<'PY'
import asyncio
import hashlib
import json
import tempfile
from pathlib import Path
from practiq_ai.config import load
from practiq_ai.contracts import DOCUMENT_MEDIA_TYPES, DocumentReference, document_source_key
from practiq_ai.office_service import convert_office, engine_identity

async def main():
    config = load()
    output = Path(tempfile.mkdtemp(prefix="practiq-office-evaluation-"))
    print(output, flush=True)
    fixtures = Path("../app/fixtures/office")
    sources = sorted(fixtures.glob("*.doc*")) + sorted(fixtures.glob("*.xls*"))
    sources.append(fixtures / "regressions/table-ending.docx")
    records = []
    for source in sources:
        payload = source.read_bytes()
        sha = hashlib.sha256(payload).hexdigest()
        kind = source.suffix[1:]
        reference = DocumentReference(objectKey=document_source_key(kind, sha),
            sha256=sha, sizeBytes=len(payload), mediaType=next(iter(DOCUMENT_MEDIA_TYPES[kind])),
            sourceType=kind, fileName=source.name)
        for mode in ("pdf", "text"):
            destination = output / source.name / mode
            destination.mkdir(parents=True)
            results = await convert_office(reference, payload, mode=mode, config=config, timeout=180)
            for result in results:
                (destination / result.name).write_bytes(result.payload)
                records.append({"source": source.name, "sourceSha256": sha, "mode": mode,
                    "output": str((destination / result.name).relative_to(output)),
                    "sizeBytes": len(result.payload), "sha256": hashlib.sha256(result.payload).hexdigest(),
                    "hasContent": result.has_content})
        assert hashlib.sha256(source.read_bytes()).hexdigest() == sha
    (output / "conversion.json").write_text(json.dumps({"engine": engine_identity(config),
        "artifacts": records}, indent=2) + "\n", encoding="utf-8")
asyncio.run(main())
PY
```

Compare the retained PDF/TXT/CSV files with the inputs: equations, icon, all 70
table rows, the final row exactly once, and visible/hidden worksheet content.
Keep the first failure and record the source/engine identity, output hashes and
manual observations. Successful conversion is not a fidelity pass. The focused
worker/service tests in the linked guide use controlled engines and model fakes;
they do not replace this deployed-engine inspection or live extraction evaluation.
