# 性能、体积与代码复用优化

2026-09-25，基线为 `2c3435e`，优化结果在提交前从本地工作区采集。原始数值与安装包检查结果见 [performance-20260925.json](performance-20260925.json)。未调用真实模型，未使用个人题库；报告不代表发布或真实模型验收。

## 实施项

| 优先级 | 路径 | 已实施方案 |
| --- | --- | --- |
| 第一批 | Python 安装包 | 排除已退役的 `langgraph_api`、`langgraph_runtime_inmem`、`langgraph_grpc_common`，同时检查 PyInstaller 模块图与发行包清单。相关 gRPC 和 Rust JSON Schema 二进制随不可达依赖移除。 |
| 第一批 | 开始练习、合并、编辑 | 按选中根题／题库读取；编辑仍全局检查 ID 冲突，保留事务和旧快照。 |
| 第一批 | 草稿与听力 | 前端合并等待中的草稿，只写正在执行版本及最新版本；离页与交卷等待写完。原生仅展开目标题及父题、共享选项依赖，校验不复用词库时保留同组作答。听力进度仅读取目标题 JSON。 |
| 第一批 | 同页裁剪 | 每页只解码和转换 RGB 一次，逐图保持原 JPEG 参数、大小限制、失败位置与来源引用。 |
| 第一批 | 原生关联读取 | 明细、选项、来源、警告、素材、缺失资源按范围批量读；增加反向关联和素材范围索引。组关系保留原顺序与完整引用，只为选中题目分配输出。 |
| 第一批 | 冻结快照 | `freeze` 用集合去重，`thaw` 先建立关联索引，消除逐题扫描全部组／素材；输出复制成本仍与实际输出量有关。 |
| 第一批 | 契约与分类 | Python 契约生成任务摘要／审核 TypeScript 类型、题型映射及 Rust 分类元数据，统一筛选校验；英语新题型进入 SQL 候选路径。 |
| 第二批 | 编辑资源清理 | 不删除节点、不替换音频引用的成功编辑跳过全库资源回收；失败、删除和启动仍执行清理。 |
| 第二批 | 备份一致性 | 用 `UNION ALL` 聚合专表计数和类型一致性，不再为这一步完整构造题目并逐题查询 11 张表；保留其他备份、资源和快照校验。 |
| 第二批 | 字体 | 构建时仅移除 KaTeX 的 WOFF／TTF 回退，保留全部 19 个 WOFF2 文件；未改公式渲染器。 |
| 第二批 | 任务与批次 | 每页最新运行记录合并为一次 SQL；本地批次历史每页 20 个，运行中批次固定可见，当前任务导入错误独立于历史页；每页凭证核对复用一个 SQLite 连接。 |
| 第二批 | 算法 | 相邻文本块按来源位置索引候选，未定位来源保留歧义回退；空位编号和排序题查找使用 Map；组卷子集和首次命中目标即停止。 |
| 第二批 | 原生体积 | release 启用 ThinLTO 与符号裁剪，保持默认速度优化等级；未引入依赖或改变数据库／快照版本。 |

## 本地测量

环境：Apple M4、16 GiB、macOS 27.0（26A428）、Python 3.14.7、Rust 1.98.1、Node.js 22.23.2。桌面数据为 5000 道简单判断题及 1000 题会话，使用临时数据库；每项三次取中位数，草稿连续写入 100 次另记 P95。计时包含 JSON 序列化，不包含 IPC 和 WebView 绘制。未清理系统文件缓存，结果不代表真实大材料题或生产容量。

| 操作 | 优化前 | 最终优化后 | 耗时降低 |
| --- | ---: | ---: | ---: |
| 全部 5000 题读取 | 205.75 ms | 93.61 ms | 54.5% |
| 20 题小库 | 1.61 ms | 1.27 ms | 20.7% |
| 首屏 30 题 | 2.55 ms | 2.15 ms | 15.6% |
| 1000 题会话读取 | 13.16 ms | 12.94 ms | 1.6% |
| 保存并返回完整会话 | 18.06 ms | 16.15 ms | 10.6% |
| 单次草稿写入 | 4.84 ms | 3.19 ms | 34.1% |
| 连续草稿写入 P95 | 4.84 ms | 3.15 ms | 34.9% |
| 1000 题交卷 | 22.09 ms | 21.79 ms | 1.4% |

会话读取和交卷的微小变化按噪声看待。原始数据还保留启用发布参数前的中间测量，不能将不同阶段的小幅差异单独归因于 LTO。前端阻塞写入回归验证：第一笔未完成时连续修改 20 次并切题，共执行两笔草稿写入，最后一笔落盘后才切题；失败恢复仍由既有回归覆盖。

同一张 2480×3508 PNG 裁剪 50 个区域：逐区域解码 **902.56 ms**，同页批处理 **33.54 ms**，降低 **96.3%**，逐字节相等。两个各含 1000 道题的完整重叠块合并为 1000 道题，中位数 **38.60 ms**。后者为当前实现绝对耗时，未据此声明端到端解析加速比例。

| 构建产物 | 优化前 | 优化后 | 说明 |
| --- | ---: | ---: | --- |
| Python 可执行目录 | 137,426,092 B | 98,052,807 B | 减少约 37.55 MiB／28.7%；同解释器新鲜基线，排除符号链接重复计数。 |
| 前端 dist | 2,469,461 B | 1,651,152 B | 减少约 33.1%；其中字体回退文件减少 816,780 B，包含功能代码变化。 |
| 原生可执行文件参数试验 | 24,278,416 B | 18,855,984 B | 同配置默认 release 对比 ThinLTO＋strip，减少 22.3%。 |

最终本地 `.app` 共 **128,213,385 B**（不重复统计符号链接）；它与原生参数试验的嵌入配置不同，不混用两者作体积对比。生成的是本地 `.app`，未制作发布签名、公证或上传。

## 验证与复现

- `make verify`：546 项测试通过，94% 覆盖率；Ruff、Pyright、锁文件、评估夹具、恢复探针及 Python 包构建通过。
- `make app-check`：133 项前端测试、75 项 Rust 测试通过；契约、格式、Clippy 通过。默认跳过系统钥匙串测试及手动性能负载；性能负载另行显式运行。
- 回归覆盖按范围读取、无关题库损坏隔离、ID 冲突、明细缺失／重复／错类型、旧备份可选索引、共享词库互斥、英语题型组卷、不可变快照、草稿合并、批次分页与页外错误、裁剪失败位置及最新运行批量查询。
- 双语浏览器验收与富文本验收通过：中文、公式缩放、表格、图片、960／1280 布局、放大／焦点和 WOFF2 加载。旧富文本夹具同步为现有二进制素材命令。
- `npm run tauri -- build --bundles app` 通过；对实际 `.app` 内服务执行 `check-bundle.py`，PDF/TXT/CSV/PNG、原生 PDFium、鉴权、禁用格式、主观评分与幂等重放通过。模型为本地替身。

## 仍然存在的成本

会话 JSON 仍须线性解析；这次减少展开与复制，没有宣称单题写入为 O(1)。有歧义的重叠文本仍保留成对比对，来源文本定位也未改变。历史批次仍 O(历史数量) 扫描清单，分页限制的是凭证核对、IPC 与渲染；只有目录读取成为实测瓶颈时再加持久索引。未增加物化任务摘要或结果缓存，避免引入新的失效和恢复协议。真实模型质量、端到端解析延迟及干净 Mac 安装验收仍需独立测量。
