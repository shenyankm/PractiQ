# P1 小程序安全接入

范围仅限答案隐藏、当前权限、鉴权/幂等与缓存清理。不代表其他 PRD 页面功能已完成，也不代表微信真机或独立安全审查已通过。后端与增量数据库部署见 [P1 后端契约](P1-backend-contract.md)。

## 学习与管理

- 题目编辑调用 owner-only `/questions/{id}/management`；普通详情仍调用学习读取，显式关闭 `revealAnswer`。题库 items 不再请求 owner 答案。
- `feedbackVisible` 不考虑所有权。无会话不显示答案；普通练习提交后可见，exam 仅 `completed` 可见，`abandoned` 不解锁。
- 结果页重新读取会话后决定解析可见性，null/省略的正确性显示“待公布”，不当作错误或零分。完整答案版本编辑、更多富内容/反馈体验不在本次范围。

## 在线可见性与内存

- 23 个业务页面统一导出 `protectedPage`。冷启动无内存会话时不挂载业务内容，统一返回登录页。
- 首次展示、页面再次显示、应用回前台、网络恢复时，先遮蔽页面，验证当前用户并等待页面的 `usePageLoad` 重新读取服务器状态，成功后再显示。不读取旧业务 storage；删除原首页分析缓存通道。
- 普通 hide/后台/文件选择或微信支付返回不卸载表单：只在同一账号运行内存保留用户未提交输入和未决操作，不提供离线提交或自动 outbox。题库/题目编辑只保留用户实际改过的字段，未改动的服务器字段重新读取；练习恢复保持当前题号及未提交输入；搜索恢复清空结果。
- 当前资源 GET 的 403/404 卸载全部业务页内容（保守全失效，不维护复杂 bank 依赖缓存），清除草稿、题干、结果、分析、邀请及媒体。网络失败/离线先隐藏，不展示旧内容；用户重试或恢复后必须重读。权限错误不会自动循环重试。写入的预期业务 403/404 只触发在线复验，由随后的资源 GET 判定是否真正撤权；普通 400/409/422 不当作撤权。
- 小组退出/移除/解绑、删除及封禁成功触发全业务可见性失效与重读。小组分享在未验证可见状态不带旧小组名称或邀请 token。未接入服务端推送撤权：持续停留页面时以新请求的权限检查、网络事件及前后台复验为触发，不声称无需通信即可得知远端变更。
- 登录、退出、失效、换号增加账号代次；refresh 只轮换同用户 token。旧代次 API/refresh/上传/支付返回不可写入新会话，旧页面作用域 API 也不能在选择文件/确认框返回后替新账号发起操作。退出先撤销本地可见性，不等待服务器响应。
- 启动清除旧版本 `practiq:v2:<userId>:` 业务缓存，退出/换号按旧用户清除；不删隐私同意等非业务 key，不写 token。缓存清理失败也不能保留旧会话或接纳新会话。底层设备 storage/临时文件删除失败并非可由应用保证消除：失败时保持不可见；媒体仅保留路径用于下次清理重试，不重新显示。

## 写入重试

- `ApiClient` 统一覆盖普通 POST/PUT/PATCH/DELETE，包含 multipart 上传。未决尝试按账号代次、用户、method、完整 route/query、body、上传路径及请求头区分，JSON 在首次 await 前快照。
- 同时重复点击合并正在执行的同一尝试。网络失败、5xx、409 `REQUEST_IN_PROGRESS`、无法确认成功响应格式时保留 key；401 内部 refresh 复用原 key/body。成功或确定 4xx 结束尝试，再次相同 payload 的新动作生成新 key，不做永久 payload 去重。
- 无自动后台重发。一般未决 key 在本次运行内保留至 24 小时接纳窗口，支付创建为 30 分钟；退出/换号清空。进程被杀/冷启动不恢复内存尝试，不宣称跨进程离线任务恢复；遇到未确认结果应先查看服务器状态。
- 导入创建→上传→解析、媒体上传→关联使用 `PendingTransfers` 保存当前账号内已发起操作的最小参数：目标 bank/question、已返回 job/media ID、原文件临时路径/名称/摘要/大小、阶段和稳定 key。navigateBack 销毁页面后重进按目标恢复，先联网复权、查询已知任务/媒体，再由用户继续；已知步骤不重新 create，未知 create/upload 结果保持原身份/key。成功、明确放弃、账号变化或资源撤权时清除；普通 hide/离线不清除，也不自动发请求。
- 文件丢失/摘要或大小改变时阻止直接重放并明确提示；改选文件须先确认放弃本地恢复，之后使用新 key。放弃只结束本地恢复，不取消、删除或退款服务端任务。超过 24 小时的未决操作不盲目新建；已知资源上的确定 4xx 保留最小收据并阻止盲目重启，需核对后明确放弃。服务端已确认上传或处理的任务可从已知阶段继续，不必重新提供已经不需要的临时文件。
- 未提交草稿不做跨页恢复，不增加 storage、离线队列或通用页面恢复框架。题库创建→标签仍仅保存本页步骤 ID，主动销毁页面后不恢复该流程；管理员 CSV 单步上传也没有跨页文件选择恢复。本有限收尾不扩展这些流程。三个上传入口的页内 401/网络重试仍使用原文件与 key，不因随机 multipart boundary 换 key。
- 登录/refresh/logout 与退款不套一般 24 小时策略。支付创建保持 Java 的 30 分钟查单/替换协议；微信取消/返回后复用当前 pending order，成功终态后新购买是新动作。账号变更清空待恢复订单，旧支付回调不能发起新账号查单。

## 图片与 HTML 的保守边界

- 仅允许配置的 API 同源、精确 `/api/v1/media/{positiveId}/content` URL（或对应相对路径）。先鉴权读媒体元数据，再用统一鉴权协议的 `Taro.downloadFile` 下载；收到 401 刷新重试，403/404 撤权。
- 仅使用 downloadFile 返回的临时路径；不调用 saveFile、不写永久文件缓存。校验 HTTP 200、允许图片 MIME、声明/实际大小不超过 10 MiB、图片签名；拒绝把 JSON 错误显示为图片。下载收到 Location 时中止，生产必须保持 HTTPS、无媒体重定向且正确配置微信合法下载域名。未在真机验证平台重定向/下载事件时序。
- 失效、隐藏、组件销毁清除自己的临时文件；迟到下载也删除、不展示。不扫描或清空微信临时目录。失败删除保留路径供下一次清理重试。
- 外部 URL 与无法证明来源的内联 URL 显式显示“来源无法验证”，不发 token、不静默假装成功。当前产品未定义经过校验的持久内联图片读取契约；Python 的视觉输入 data URL 不是小程序产品媒体契约。
- HTML 使用 `Text` 显示原始文本并说明安全预览，不运行 RichText 的外部图片/网络资源，也不自制正则 HTML sanitizer。这是本轮明确的受限降级；不扩展音频、HTML 编辑或其他富内容功能。

- `make test`：Node 行为测试、严格 TypeScript、WeChat 测试构建。
- 新测试覆盖稳定 key/终态边界、401 上传、账号代次、清理、30 分钟支付、媒体鉴权与临时文件；真实 React reconciler 挂载实际保护边界与题目/题库编辑、导入页面，验证遮蔽→复验、草稿保留、服务器字段更新、导入/媒体页面销毁重进后恢复原操作。`pending-transfers.test.ts` 另验证未知结果同身份/key、服务端已完成步骤、文件失效/改选、确定 4xx、24 小时边界与账号/撤权清理在途请求。测试使用 Taro 自带 reconciler、假平台/HTTP，不加依赖、不调用真实微信/支付/模型。
