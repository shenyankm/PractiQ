## 来源与边界

全部图片为 Chromium 响应式界面，使用仓库预览数据、合成 native IPC 或 HTTP 响应。
“移动端”和“桌面端”表示布局尺寸；Android 浏览器项目包含触摸模拟与生产静态构建导航检查。
这不等同于 Android APK、macOS/Windows 原生窗口、系统文件选择器、软键盘/IME、物理设备或真实模型/服务验收。
未改变服务接口、数据库、文件权限、密钥存储或持久化练习格式。

重点矩阵覆盖两种主题与两种语言；其他场景以各自测试实际采集组合为准，不声称穷尽所有数据和窗口组合。
截图采集时使用基准提交与工作区修改；后续分组提交不改变这些采集证据。基准提交、采集时的已跟踪 diff 摘要及新增源文件摘要保留在 JSON 清单。
每张图含实际视口、图片像素尺寸、主题、语言、字节数、SHA-256 和采集测试出处。
哈希相同的截图只保存一次，其他来源保留为 aliases（`sources`）。

## 重新生成

从仓库根目录安装已锁定的 App/Web 依赖后执行：

```sh
(cd app && npx playwright test --project=preview --project=rich-content --project=mocked --project=android-390 --project=android-360 --output=.build/uiux-accepted-results)
(cd web && npx playwright test --output=.build/uiux-web-results)
python3 docs/evidence/2026-10-21-uiux-fixes/build-gallery.py
```

生成器只读取成功测试的采集记录，按平台连续编号，检查文件存在、SHA-256、字节数、编号连续性、重复哈希和 CSV 行数。
离线索引每个平台拥有独立的搜索、场景、状态、视口、主题、语言和构图筛选器。
