Ranked hypotheses before production edits:

1. **App feasible counts for uniform complete groups.** Current paper.rs only fast-paths all-unit roots. The new current-source probe finds 100k weight-3/10 groups require about 92 ms. User impact: exact group-compatible count choices in practice/exam setup. Minimal extension of the existing shortcut; no new dependency/schema/cache.
2. **App mixed groups that saturate their possible sum interval.** The same probe exposes about 99 ms for alternating 2/3-leaf roots. Static loop termination demands the unreachable count 1. Global eligible minimum can bound possible states without changing first-written paths. Requires full count-preview regression controls because exact selection shares the helper.
3. **Server visual-result merge copies comparison content it cannot use.** Current baseline cProfile measures 1000 _content dumps (~6.4% of profiled merge). Production document._merge passes overlapping=False for pages. Preserve all deep copies and validation; skip only this comparison dump. Text overlap is a control.
4. **Web unchanged diagnostic reserialization.** Production probe measures 31 repeated JSON.stringify calls for a 1.48 MB diagnostic object over ten unrelated task-state filters (~1–1.2 ms each). Parent list polling similarly updates list state while detail identity remains unchanged. Memo the existing Usage component; preserve eager initial and open behavior and live detail updates.
5. **App quota ordering repeats full candidate scans inside sorting.** Current full native 100k-root preview is about 316 ms ordered / 206 ms seeded random. Selection-specific roots.iter().position sorting can be replaced by Set membership and one ordered root pass. Full preview hashes must preserve chosen order, supplied answers, scores and digest.
6. **Server export synchronously prepares result JSON before its first await.** Static current code evidence only; localization and wall/heartbeat baselines must establish whether moving CPU work into the existing joined thread helper has a reliable benefit. GIL may negate it.
