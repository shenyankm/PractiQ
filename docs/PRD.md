# PractiQ 单用户产品需求

## 产品目标

个人在本机浏览器整理题库、导入学习材料、进行练习与模拟考试，查看统计及 AI 建议。前端只做 Web，适配手机视口与桌面，不提供小程序或原生客户端。

## 功能

- 学习首页：累计作答、正确率、收藏题库、最近练习及继续练习入口。
- 题库：创建、编辑、软删除、收藏、标签、树状目录；题目列表支持分页与筛选。
- 题目：选择、判断、填空、简答；题干、解析、选项、答案版本、草稿/发布/归档、知识点关联、内容块与媒体附件。
- 材料分组：共享材料标题与正文，维护组内题目。此功能不是多人学习群组。
- 练习：顺序、错题、题型和考试模式，最多 500 题；固定开始时的答案版本，重复提交不重复计分；简答题对照参考答案自查。
- 考试：交卷前隐藏答案、得分及正确性，统计不泄露未完成考试成绩；放弃的考试不开放答案。
- 导入：UTF-8 文本/CSV、PDF、DOCX、XLSX、图片，先上传再提交解析，支持状态查询、事件/结果分页、失败重试与取消。解析生成草稿供核对后发布。
- AI：后台文档解析、答案生成、学习报告；记录调用用量，不设置会员或积分限制。
- 搜索分析：题干检索、总体/题库统计、薄弱题目、近期趋势、任务与报告历史。
- 设置：知识点维护及浏览器恢复信息清理。

## UI 约束

React 19 + Vite + TypeScript + HeroUI v3。所有可用控件使用 HeroUI 默认样式。禁止业务 CSS、内联样式、主题覆盖、任意值及视觉工具类。仅允许标准 Tailwind 布局工具类。375px 单列与移动导航，768px 起侧栏，宽屏多列，内容与操作不溢出或遮挡。

## 非目标与数据

没有用户系统、登录、权限角色、会员、积分、支付、退款、学习群组、邀请、公开题库和排行榜。产品 API 与 AI 服务分别运行。初始化全新 PostgreSQL 数据库，不迁移、清空或改写旧数据库。默认仅本机访问，移动端适配指浏览器布局适配。

## 完成条件

真实 PostgreSQL 完成核心 CRUD、练习、幂等和 worker 异常恢复测试；Web 完成样式规则、类型、构建与三个视口的浏览器验证。AI 测试使用替身，外部配置不足时不声称真实模型 联调完成。
